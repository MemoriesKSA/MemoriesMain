# MEMORIES Travel

Initial production-ready foundation for the MEMORIES travel website.

## Stack

- Next.js App Router
- React
- TypeScript
- Vercel-ready configuration

## Local development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Deployment

Import this repository into Vercel. Vercel will detect Next.js automatically; no custom build settings are required.
